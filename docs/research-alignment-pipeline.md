# 统计门控稀疏 MDL 对齐方案

> 状态：`mdl-v1` 已作为生产默认；收敛求解器位于正式
> `src/dualign/algorithms/mdl` 包，由 `src/dualign/core/aligner.py` 通过稳定门面调用。
> 旧 `legacy-anchor-v1` 只保留显式 CLI benchmark，不作拒绝回退。
> 本文同时规定算法流程、拒绝语义、参数依据和能力边界。

## 1. 输出契约

输入是同一嵌入模型编码的两份非空、保持原顺序的双语 Markdown 行序列。算法只表达：

```text
1:1 / N:1 / 1:N / 1:0 / 0:1
```

满足“存在双语对应且主要对应单调”时，输出完整覆盖路径；不满足时拒绝。一般 `N:M`、
交叉关系和块置换不由行级 DP 伪装成 merge 或 gap。组合证据的两个合理编码若产生不同
路径，输出保守的 provisional 路径并将差异区标为 `needs_review`，不得称为确定结果。

## 2. 离线校准与唯一政策参数

每个 embedding 模型、语言对和领域版本维护：

1. 真实非对应文档对的存在性 null；
2. 真实平行文档中 `(最大加权单调链外 mutual 对数, mutual 对总数)`。

自由决策标量只有 `alpha`，表示门控声明的错误率。默认 `.05` 是产品政策，不是从异常
案例调出的对齐阈值。Zipf、Elias-delta 和 beta-binomial 是可替换、可检验的模型假设；
操作语法是任务定义。

校准集大小决定 conformal p-value 分辨率。`N` 个 null 的最小 p 值为 `1/(N+1)`；因此
`alpha=.05` 至少需要 19 个 null 才可能接受任何对应关系。当前 20 对探索集只能证明流程
可运行，不能给出稳定的跨领域错误率。

当前探索产物以审阅清单的循环后一文档构造错配，使每份文档在两侧各出现一次、没有自配、
没有随机种子或搜索配对。这给出平衡且可复现的 hard-negative 校准，但相邻清单可能来自
近似领域，样本也不独立；因此只称“校准自检”，未来必须用预先冻结的独立错配集验证。

## 3. 全流程

### 3.1 原子矩阵与序数证据

归一化向量后计算全文余弦矩阵 `C`。每个格点分别在行、列内排名，以有限 Zipf 码得到
相对均匀选择节省的 bits，并取较弱方向：

```text
e(i,j) = min(row_rank_saving(i,j), column_rank_saving(i,j))
```

因此对严格单调分数变换不变，但它只说明相对最像，不说明文档确实对应。

### 3.2 两级统计拒绝

第一层检验“无对应”假设：

```text
T_exist = 0.5 * (mean_i max_j C(i,j) + mean_j max_i C(i,j))
```

用真实错配 null 的 conformal 上尾 p 值；`p > alpha` 时返回
`rejected_no_correspondence`。

第二层检验顺序与真实平行文档是否相容。从 mutual-nearest 对求最大 rank-code 权重递增
链，记 mutual 对数为 `K`、链外数为 `X`。校准模型为：

```text
theta_d ~ Beta(a,b)
X_d | theta_d,K_d ~ Binomial(K_d,theta_d)
```

`a,b` 由平行校准文档的链外率矩估计。posterior-predictive 上尾概率不大于 `alpha` 时
返回 `rejected_order_incompatible`；没有 mutual 对时返回
`rejected_order_unidentifiable`。链覆盖率与 Kendall tau 仅作诊断。

旧版“199 次顺序随机化”已从主流程删除。它检验的是“是否比随机排列更单调”，与真正
需要的“是否符合平行语料的失序程度”不是同一假设，并与 beta-binomial 门控重复。`199`
只规定 Monte Carlo 分辨率 `1/200` 和计算量，没有来自问题结构的依据；短文档即使顺序
完美也可能无法达到 `.05`。删除后门控确定、无随机种子，也不再有模拟预算参数。

### 3.3 无阈值脚手架与单覆盖候选图

最大加权递增链只作脚手架，不是不可跨越锚点。每个内部脚手架点建立一个窗口：

```text
[前一脚手架点, 后一脚手架点]
```

每窗运行任意连续 `N:1/1:N` 的局部 MDL，并提交每个非支配复杂度的最佳路径支持边。
所有中心窗只有一个与奇偶无关的覆盖；每个锚点都位于某个窗口内部，可以被跨越。脚手架
自身的 `1:1` 也只作为候选边。

这取代“两遍交错”：没有 parity、固定窗宽、锚点密度阈值或每窗保留 K 条路径。若脚手架
稀疏，窗口自然变大并趋向完整 MDL；这是信息不足导致的实际计算退化，不隐藏为启发式
截断。

### 3.4 原子 MDL 与精确 gap 商图

结构复杂度为 `1:1=0`、`N:1/1:N=N-1`、每条 gap 行为 1。结构码使用完整语法中同复杂
度脚本数和 Elias-delta 增量码：

```text
objective = semantic_bits - structure_bits
```

若一条路径有 `r` 条语义关系，复杂度恒为：

```text
c = n + m - 2r
```

因此 gap 网格的走法不含信息，可精确取商。中心候选与组合验证共用同一个求解器：在稀疏
语义边上求固定关系数的最大权单调链；source 扫描配合 target Fenwick 前缀 Pareto 结构，
不访问二维 gap 网格。全 gap 路径天然存在，不需要另造完整候选路径。这是等价变换，不是
走廊近似。

### 3.5 决策相关组合候选

拼接编码只用于能验证或翻转原子路径的边：保留全部免费 `1:1`，验证已选复合边，对 gap
与相邻语义边提出一次边界移动，并递归实体化复合边的直接前缀/后缀，使
`H_subblock+gap` 成为候选图中的真实路径。规则只依赖图结构，没有跨度上限和语义阈值。

每个复合候选编码完整拼接块与 leave-one-line-out 块。当前保留两个有不同反事实含义的
码，而不以经验权重混合：

- `P`（posterior reweight）：原子覆盖分布按完整块增益秩归一化重加权，较宽松；
- `D`（counterfactual DLD）：`最佳直接子块 bits + 被删行必要性秩节省`，较保守。

两者都把增益放到同文档对侧原子行形成的有限秩 null 中，故能与原子 bits 相加，无余弦
差倍率。两模型共享一次批量编码缓存，并在同一精确稀疏 MDL 上求解。三条路径承担不对称
角色：原子路径 `A` 是未组合验证的诊断基线，`D` 是最终 provisional 路径，`P` 是较宽松
的备选提议。`A` 不参与状态决策；`D=P` 时状态为 `aligned`，`D!=P` 的每个最小分歧岛
都输出 `needs_review`。因此不会再由 `D` 是否恰好等于原子基线来压制组合模型分歧。
这是一条两模型结构确认规则，不使用分数边距或语义阈值。等权混合曾在真实审阅中明显
退化，已从代码删除。

GUI 的 `[F]` 也不再覆盖整个分歧岛。若两条路径对某行的“语义关系 / gap”归属不同，
只标记包含该行的当前关系；若所有行都保持为语义关系、只是对应对象改变，再按关系的
pair incidence 标记。注释同时保存当前与备选结构。算法产生分歧的历史状态与用户是否已
完成审阅仍是两个概念。

## 4. 复杂度与退化

设向量维数 `d`、矩阵 `n*m`、中心窗口访问格点总数 `S`、局部前沿宽度 `W`、组合语义
边数 `E`、稀疏链前沿宽度 `Q`：

- 余弦矩阵：`O(n*m*d)`，当前内存 `O(n*m)`；
- 双向排名：约 `O(n*m*(log n + log m))`；
- 顺序证据：`O(K log K)`，无随机重复；
- 局部 MDL：约 `O(S*W)`；
- gap 商图：约 `O(E*Q*log m)`，内存 `O((E+m)Q)`；
- 组合编码：与实际决策相关复合块及消融数成正比，每个块还与对侧原子行点积。

高平行文档中脚手架密，`S` 接近线性；低锚点但门控仍接受的相关文档中，中心窗口可退化
到 `O(n*m*W)`。完全非平行文档通常在局部 MDL 前拒绝，但门控仍必须支付余弦矩阵和排名
成本。不存在既不看跨文档相似度、又能统计拒绝非对应的免费捷径。

长复合边的前后缀闭包最坏可生成二次方文本。目前不设任意跨度阈值；若真实语料出现该
退化，应改为按分歧区惰性展开，并以“路径仍有分歧”为继续条件，而不是按余弦或长度截断。

## 5. 2026-08-24 全量复验

在 292 个存在旧生产异常、向量和组合文本缓存全命中的真实文档上：

- 新单覆盖候选图与此前路径闭包 DLD 最终路径 `292/292` 完全一致；
- 门控接受 `292/292`；校准自检中存在性拒绝 `20/20` 循环错配，顺序模型拒绝全部 20
  文档的两种四块乱序（`40/40`）；这不是独立测试集上的泛化率；
- 两模型共用后只编码 825 个唯一组合文本；
- `36/292` 文档含 45 个组合模型分歧区；
- 全流程总计 `44.10 s`，中位 `0.0997 s`，P95 `0.437 s`；其中中心候选 `17.61 s`，
  两次组合求解共 `5.27 s`。

先前含 199 次随机化、单组合模型的精确商图全流程为 `91.53 s`、中位 `0.246 s`。两批
运行不是严格微基准，但路径不变且主要删除的是确定的重复计算。生产算法在高度平行章节
仍常为 `0.x s`，所以只能说已达到同一实际量级，不能声称所有文档等速。

既有人工审阅表明，`P` 的旧差异岛为 50 修正、45 退化、1 等价、3 歧义；路径闭包 `D`
为 39 修正、14 退化、1 等价、1 歧义。两模型相对于生产 baseline 提出相同改动的已知岛
为 37 修正、5 退化、1 等价、1 歧义。它说明分歧暴露有价值，也说明共识仍会错。

## 6. 能力边界声明

以下是模型边界，不应通过新增案例阈值逐个“修复”。

1. **语义不存在性依赖域内校准。** 纯 rank evidence 无法区分全局低分矩阵和高质量矩阵；
   embedding 或领域变化后必须重建 null。20 对 null 的证据远不足以宣称广泛拒绝能力。
2. **一般乱序不属于单调行对齐。** 大块换序应先由独立块匹配/置换层恢复顺序；局部少量
   逆序、重复句和 mutual 对很少时，统计检验可能没有足够功效。
3. **当前语法不含一般 N:M。** 两侧都拆分、交叉引用、目标把非相邻源句合并时，即使人
   能判断，路径语法也无法忠实表达。
4. **句向量不保存词项覆盖与翻译蕴含。** 同主题译注、说话人归属、专有名词、否定、数值、
   极短应答和标点差异可能具有近似向量；原子相关不等于“每部分均被翻译”。
5. **拼接增益不是翻译充分性的证明。** 乱码、译注和相关正文都可能提高完整块余弦；消融
   也会误伤自然段、表单字段和排版续行。组合秩码只能提供软证据。
6. **重复或低信息行本质多解。** “啊”“是”“……”等在邻域内可有多个结构等价或语义
   不可辨答案；机器不应伪造唯一置信结论。
7. **源文本质量问题不能由余弦变化诊断。** OCR 乱码可能让余弦上升；缺行、错行、语言
   混杂和错误章节配对应由数据质量层报告。
8. **统计通过不等于逐行正确。** 门控只判断文档级适用性，不能为每条关系提供校准置信度；
   `aligned` 也仍受 embedding 和候选覆盖限制。
9. **最坏计算仍可能大。** 相关但低锚点的长文档会逼近完整二维 MDL；超长复合跨度会扩大
   消融闭包。应报告并中止资源超限，而不是静默改变目标函数。

可接受的下一层研究应引入真正新增的信息，例如只在 45 个模型分歧区计算双向 token/短语
覆盖码或经独立数据校准的跨编码器似然。若新证据仍冲突，应保留人工复核；不再增加
merge penalty、gap penalty、跨度阈值、按案例余弦阈值或例外规则。
