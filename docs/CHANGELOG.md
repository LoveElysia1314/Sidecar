# 更新日志

> v0.8.0 之前处于快速开发阶段。这里按产品能力里程碑记录，不再把每次内部架构调整单独作为产品版本。

---

## 0.8.0 (2026-09-03)

### 产品收敛

- 删除依赖小样本校准资料的文档平行性门控；改为直接尝试对齐，并以固定 60 秒限制原子候选与全局求解。
- 原始 embedding 和后续合并候选编码不计入原子对齐时限；报告分别记录准备、原子对齐、组合处理和总处理耗时。
- 简化 GUI 与报告概念，不再向用户暴露校准身份、工作量代理和求解器内部状态。
- 保留固定的相似度矩阵容量保护；不提供额外配置或延长时限重试。

### 审校与维护

- 优化文本对表格复制格式，将当前评分纳入表格；修复重置修复操作后当前评分未更新的问题。
- 保留无界面审校能力；失败的 embedding/观察者实验及其本地资产退出产品仓库。
- 删除旧校准资源、校准 benchmark 和过时评估脚本，并使用 Black 统一格式化全部 Python 代码。
- 移除静态审查确认的无引用内部代码，合并重复算法文档，清理已经失效的设计稿与实验说明。

---

## 0.8.0-rc.1 (2026-08-28)

- 建立以审校区为原子单位的 AI 责任编辑工作流，可调阅相邻上下文、执行结构编辑并取消长时任务。
- 统一跨关系编辑、手动校订、文本搜索、文件对状态列表和固化差异审查。
- 修复来源、操作和人工认可的分层语义；重对齐与固化只迁移仍然有效的工作状态。
- 组合证据增加真实硬边界复核；长时任务改为响应式模态进度窗口。

---

## 0.8.0-beta.1 (2026-08-26)

- 将 `report.json` 确立为唯一工作状态，建立稳定关系身份、可重放修订和审核资产迁移。
- 默认算法迁移为稀疏 MDL，旧锚点算法冻结为显式 benchmark；组合分歧成为可审阅状态。
- 新增正文固化预览、应用、批处理和可恢复事务；普通保存只更新报告。
- 全局化 SQLite embedding 缓存，显式版本化报告，并改善 Windows 原子替换可靠性。

---

## 0.8.0-alpha.1 (2026-08-18)

- 增强 OpenAI Responses API、Ollama 兼容后端和推理强度配置。
- 改善 embedding 批处理与错误恢复；引入 uv、依赖锁、Windows 启动器、统一版本元数据和 Black。
- 修复缓存连接、API Key、GUI 定时器、DP 边界和发布脚本等可靠性问题。

## 0.7.0 (2026-06-21)

- 建立递归锚点与单次 DP 对齐流水线、SQLite 行级 embedding 缓存和 ProviderManager。
