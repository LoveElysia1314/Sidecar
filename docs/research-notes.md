## 对齐研究的保留结论

### 从硬锚点到软脚手架

旧算法通过互惠高分点切分文档，再在区间内补齐路径。它速度快，但锚点会过早限定搜索；一旦
正确复合关系跨越某个错误锚点，正确路径无法进入最终 DP。固定 `2:1 / 1:2`、锚点密度、gap
比例和合并触顶指标，也把生成能力、质量判断和资源保护混在了一起。

当前算法只把最大权单调证据链作为可跨越的候选脚手架。原子关系与 gap 在同一个稀疏图中
全局求解，组合模型分歧转为局部复核，不再调配经验权重或把一种解释静默覆盖另一种解释。
旧算法仅可显式用于回归：

```bash
uv run dualign align -a a.md -b b.md --algorithm legacy-anchor-v1
```

### 已否定的路线

- 两遍奇偶交错窗口仍可能同时错过跨越两个脚手架点的关系；单覆盖、可跨越脚手架消除了
  parity 参数。
- 完整拼接余弦变高不能单独证明应合并；相对最佳子块增益会误伤表格和同主题续句，不能作为
  固定阈值。
- posterior 与 counterfactual 码长的等权混合在真实异常集上不稳定；当前保留两条路径的
  分歧作为复核信号。
- Monte Carlo 顺序随机化和窗口几何工作量估计没有直接回答产品需要控制的问题，均已退出
  生产门控。
- 固定 top-k、连续多轮路径稳定和候选图按轮扩张都不能提供最优性证书，额外控制流也没有
  显示出稳定收益。

### 数值观察与模型差异

绝对余弦分布会随 embedding 模型、语言和领域改变，历史小样本模型对比只能说明这种漂移
存在，不能给新模型签发生产阈值。现行证据使用双向保守排名节省，对严格单调分数变换不变；
余弦观察固定量化为 binary16，以消除低于部署链路有效精度的伪排序，但不降低内部动态规划
精度。

这并不意味着模型质量不重要。不同模型仍会改变候选证据与最终路径，只是这种差异不再通过
一组跨模型绝对阈值表达。若未来研究平行性置信度，应建立独立、足量、文档隔离的 benchmark，
不能把诊断实验重新接成计算安全门控。

### 精确化简与能力边界

路径复杂度满足 `c = n + m - 2r`，所以同一语义关系数下 gap 的二维走法不携带额外信息。
生产求解器对 gap 网格取精确商，在稀疏语义边上求固定关系数的最大权单调链；这是目标函数的
等价变换，不是走廊近似。

人工拆分后的局部重对齐只在已选父关系内部工作。失败时保留父关系并标记复核，不调用 legacy
全文对齐，也不通过降低阈值强行产出路径。当前仍无法仅靠同一嵌入空间可靠区分同主题漏译、
译注和自然续句，也不生成一般 `N:M` 或块置换。

## 验证范围与局限

2026-08 的收敛实验覆盖 292 份含旧生产异常的真实文档，并比较主路径、备选路径和状态；它们
用于回归已知问题，不等同于独立同分布测试集上的泛化率。旧门控探索集只有 20 对文档，规模
不足以支持跨模型平行性保证，因此相应校准资料和 benchmark 已删除。

2026-09 的破坏性长文档实验定位了全局前沿的超时风险，并促成固定 60 秒原子求解边界。详细
时间口径和压力结果已合并到[对齐算法](algorithm.md)，不在多份文档中重复维护。

## 复现入口

下列脚本依赖调用方提供的数据或 `.artifacts/` 中的本地产物，不是单元测试：

| 脚本 | 用途 |
| --- | --- |
| `scripts/audit_production_anomalies.py` | 从仍与正文哈希一致的报告建立只读异常清单 |
| `scripts/benchmark_mdl_runtime.py` | 重放清单并输出路径摘要和运行时间，检查优化等价性 |

脚本不会把本机语料或实验产物纳入仓库。正式回归由 `tests/` 承担；研究脚本不能替代单元测试，
也不应使用硬编码的个人数据路径。
