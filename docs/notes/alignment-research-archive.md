# 对齐算法试错路线归档

日期：2026-08-24
用途：保留被收敛实现取代的证据，避免旧脚本和多份阶段文档继续充当现行说明。

## 已淘汰路线

### 固定 2:1/1:2 与完整跨度枚举

最初完整 MDL 从固定跨度扩展到任意连续 `N:1/1:N`。20 个完整章节中，一般跨度相对
固定跨度只增加约 5.2% 求解时间，说明主要成本来自二维格点与复杂度前沿，而不是跨度
枚举本身。完整 general-span MDL 因此保留为小规模正确性 oracle。

### 两遍交错脚手架

旧方法以偶数/奇数锚点分别作窗口边界，再将两条完整局部路径并集复合。最长
`1168×1165` 章节只访问 4,681/1,360,720 个格点，局部求解约 0.065 秒，并修正了
“Oh.”/“Ah.” 错位；但两条局部最优路径会共同漏掉 Pareto 替代边，20 章节中曾有 1 个
与完整 MDL 不同。

替代方案是每个锚点一个 `[前一锚点, 后一锚点]` 中心窗口，并提交所有局部复杂度前沿
路径。它没有 parity，且每个锚点可被跨越。2026-08-24 先删除了仅为获得完整路径而保留
的半套交错求解，随后让中心层与组合层共用精确 gap 商图，连回退路径也不再需要；两次
简化在 292 文档上都保持最终路径不变。

### 绝对拼接分数与最佳子块增益

6 个早期纯复合候选显示：完整拼接余弦升高既出现在正确自然段/表单合并，也出现在吸收
译注和漏译句；“完整块相对最佳 proper sub-block 增益”能识别明显漏译，却会轻微否定
正确表单。因此二者只可成为软证据，不能作为 merge 门槛。

### 条件后验组合秩码

完整块相对 leave-one-out 的增益在对侧全文原子行中排名，再归一化重加权原子分布，给出
可与 rank bits 相加的条件码。它在 292 文档逐岛审阅中得到 50 修正、45 退化、1 等价、
3 歧义。优点是保留原子覆盖，缺点是同主题未译行仍能贡献完整原子 bits。

### 等权通用混合

将后验重加权与反事实 DLD 以等权 mixture code 合并，得到 47 修正、30 退化；它同时
继承两者错误，并未把模型不确定性变成信息。实现已删除，保留双路径分歧更诚实。

### 199 次条件顺序随机化

旧检验固定 mutual 对与权重、随机排列目标位置，以加权 LIS 检验“比随机顺序更单调”。
`199` 仅令最小 Monte Carlo p 值为 `.005`，没有统计功效或误差界设计；而且短文档在完全
有序时也可能因排列空间太小而无法达到 `.05`。它与由真实平行文档校准的 beta-binomial
链外率门控重复，已经从决策和代码删除。若未来仅作科学审计，应预先声明模拟精度或使用
有 anytime-valid 界的序贯 Monte Carlo，不能重新成为生成算法参数。

## 保留的负面证据

- 20 个真实异常窗口的早期原子 MDL 为 16/20 正确或结构等价、3 个明确退化、1 个需要
  一般 N:M；不能只报告修正案例。
- 三处行内乱码注入未改变 mutual-rank evidence 或路径，原始余弦甚至可能升高；绝对分数
  变化不能解释为内容质量。
- 后验与 DLD 的共识仍有 5 个已知退化，集中在说话人归属、拆行和短句错位。
- 旧实验的 20 错配、6 个块乱序与后续系统化的 40 个块乱序变换都来自同一小型探索域；
  292 平行文档也不是独立测试集。这些只是回归证据，不是泛化保证。
