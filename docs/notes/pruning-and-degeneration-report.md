# 稀疏 MDL 的精确剪枝与退化修复研究

日期：2026-08-23
状态：隔离实验；未接入生产

> 2026-08-24 收敛说明：本文保留当时的分模型质量审阅。现行主流程已删除 199 次随机化，
> 以单套中心窗口和统一 gap 商图取代残余交错基线，并同时输出 P/D 分歧区。最新流程
> 和性能以 `docs/research-alignment-pipeline.md` 为准。

## 一、结论先行

本轮得到两个性质不同的结论。

第一，组合层原来的二维 gap 网格可以**精确消去**，不是近似带宽剪枝。在 292 个真实异常
文档上，保留全部语义候选时，新旧实验路径 292/292 完全相同，99 个差异岛逐岛签名也
完全相同；组合求解总时间从 505.10 秒降到 3.44 秒，中位数从 0.822 秒降到 0.0099 秒。

第二，原先 45 个退化不是一个原因：

- 11 个来自“正确复合边未进入组合验证候选”，可由无阈值的 gap 边界反事实补齐；
- 大量错误吸收来自“原子相关性被误当作翻译覆盖”，反事实 description-length
  difference（DLD）能显著减少；
- 仍有一小组说话人归属、拆行和局部错位，句向量秩与拼接消融无法稳定区分。继续调一个
  标量只会在正确合并与错误吸收之间搬运错误。

当前最稳妥的部署形式不是强迫一个模型裁决全部岛，而是双模型一致性选择：只有宽松的
后验重加权模型与保守的路径 DLD 模型给出相同局部改动时才自动采用，否则保留基线路径并
标记复核。在既有人工标签上，这保留 37 个修正、5 个退化；确定性改动的修正率为 88.1%
（Wilson 95% 区间 75.0%–94.8%）。该区间只是对本探索样本的描述，不能当独立泛化保证。

## 二、精确剪枝：消去没有信息的 gap 网格

### 2.1 结构恒等式

设文档两侧行数为 `n,m`，一条路径含 `r` 条语义关系。当前语法中的语义边只允许
`N:1/1:N`，若一条边覆盖 `a,b` 行，其结构复杂度是：

```text
a + b - 2
```

没有被语义边覆盖的每一行以 gap 付出 1。因此整条路径的复杂度为：

```text
c = Σ(a+b-2) + [n+m-Σ(a+b)] = n+m-2r
```

所以在固定 `r` 时，gap 先横走还是先竖走、经过哪些中间格点，都不改变语义证据或结构
码。旧显式求解器枚举这些格点是在枚举同一个假设的多种无信息表示。

### 2.2 商图求解

将所有纯 gap 路径取商以后，问题变成：

```text
对每个关系数 r，找权重最大的单调、不重叠语义边链
```

实现按 source 起点扫描；已结束的边进入按 target 终点索引的 Fenwick 前缀结构。每个
Fenwick 节点只保留 `(关系数, semantic bits)` 的 Pareto 前沿：若另一状态关系更多且
语义不弱，当前状态对任何未来后缀都不可能更优，可精确删除。

设稀疏语义边数为 `E`，实际 Pareto 宽度为 `W`，复杂度约为：

```text
时间 O(E W log m)
内存 O((E+m) W)
```

最坏 `W` 仍可达到 `min(n,m)`，但不再强制访问 `n*m` 个 gap 格点；非对应/乱序文档仍在
进入该层之前由统计门控拒绝。

### 2.3 全量实测

两次测量都在向量与组合文本缓存全命中的情况下运行，并保留全部 2,163 个组合文本：

| 指标 | 原二维显式网格 | 精确 Pareto 商图 | 倍数 |
| --- | ---: | ---: | ---: |
| 组合层总时间 | 505.105 s | 3.439 s | 146.9× |
| 组合层中位文档 | 0.822 s | 0.0099 s | 83.3× |
| 组合层 P95 | 5.320 s | 0.0269 s | 197.8× |
| 组合层最长文档 | 73.576 s | 0.111 s | 665.3× |
| 全流程总时间 | 585.131 s | 91.532 s | 6.39× |
| 全流程中位文档 | 1.040 s | 0.246 s | 4.23× |

当时全流程主要受全文余弦、双向排名和 199 次顺序随机化控制，而不再受组合 DP 控制。
后续审查认定随机化门控重复且模拟预算无充分依据，现已删除。不同整批运行有波动，因此
本表中的组合层对比比全流程倍数更可复现。

验证包括：

- 292/292 文档的新旧差异岛签名相同；
- 99/99 人工审阅岛的路径结构相同；
- 随机 `1×1` 至 `4×4` 矩阵上，稀疏商图与完整 general-span lattice 的复杂度、语义
  bits 和总目标一致。

## 三、编码请求的决策相关剪枝

精确商图解决的是 DP，不会减少拼接编码。编码层采用另一条可解释规则：只编码会验证或
翻转当前决策的复合关系。

1. 保留所有无需拼接编码的 1:1 提案；
2. 验证原子路径已经选择的复合边；
3. 对原子路径的 gap 与相邻语义边做一次边界移动，提出“吸收这一行”的反事实；
4. 对复合边递归补齐连续前缀/后缀，使 `H_subblock+gap` 在图中成为真实可走路径。

规则由路径结构决定，没有余弦阈值、最大跨度或每岛 K 条候选。当前路径 DLD 全量编码
825 个组合文本，相对 2,163 个减少 61.9%。长 gap 的递归子块闭包最坏仍可生成二次数量
文本；若以后遇到这种语料，应使用按边界逐层展开并在模型分歧岛继续细化，而不是设置
跨度上限。

一个较早的“只做一行边界移动”实验编码 810 个文本，并在不撤回原 50 个修正的情况下
消除了 45 个退化中的 11 个。这说明候选补齐本身有价值；下面更大的质量变化来自语义
假设更换，不应混称为剪枝收益。

## 四、退化修复模型

### 4.1 原模型为何吸收同主题漏译

原子覆盖模型把：

```text
e(A1,B) + e(A2,B)
```

解释为 `A1,A2 -> B` 的证据。若 `A2` 是与正文同主题的未译注释，它仍可能对 `B` 有较高
rank evidence。后验组合修正虽能否定一部分候选，但基数仍继承了 `A2` 的原子相关性。

### 4.2 直接反事实 DLD

新假设直接比较同复杂度的两个编码：

```text
H_merge:          完整块 -> 对侧行
H_subblock+gap:   最佳直接连续子块 -> 对侧行，其余为 gap
```

对每个对侧原子行，计算完整拼接相对直接前缀/后缀消融的增益；将增益秩转换成相对均匀
null 的有限 Zipf code saving。复合边语义为：

```text
best_direct_subblock_bits + necessity_rank_saving
```

被吸收行不再因为“主题相关”自动贡献一份原子 bits；它必须通过完整块的反事实必要性解释
自己。这里没有余弦差倍率或 merge penalty。

### 4.3 三种结果

| 模型 | 修正 | 退化 | 等价 | 歧义 |
| --- | ---: | ---: | ---: | ---: |
| 原后验组合证据 | 50 | 45 | 1 | 3 |
| 反事实 DLD，未强制实体化全部子路径 | 45 | 18 | 1 | 2 |
| 路径闭包 DLD | 39 | 14 | 1 | 1 |
| 后验模型与路径 DLD 一致的改动 | 37 | 5 | 1 | 1 |

纯 DLD 提高召回，路径闭包 DLD 更保守。两者差异不是应由一个调权常数抹平的噪声，而是
当前观测不能决定的模型不确定性。测试的等权通用混合码得到 47 个修正、30 个退化，明显
差于纯 DLD；“折中”并没有解决信息不足。

### 4.4 双模型一致性门控

用于生产安全改进时，可把现有生产路径作为 baseline，并分别生成：

- `P`：后验重加权组合 MDL，较宽松；
- `D`：显式子路径闭包 DLD，较保守。

对 baseline 与两条研究路径形成最小公共顶点差异岛。只有 `P` 与 `D` 在同一岛提出完全
相同的替代路径时自动替换；其余岛保留 baseline 并标记“模型分歧”。这是一种 Pareto
判定，不需要置信阈值：候选必须同时被两种描述长度解释支配。

既有 95 个可明确判断的旧差异岛中：

- 自动接受 37/50 个已知修正；
- 仅保留 5/45 个已知退化；
- 确定性接受项修正率 37/42 = 88.1%；
- 放弃 13 个可能修正，以换取拒绝 40 个已知退化。

这是适合渐进替换生产算法的“安全改进”策略，但不是独立生成算法的最终答案；独立模式
应把分歧岛作为显式未决输出，而不能假装已经可靠裁决。

## 五、仍未解决的共识错误

两模型共同保留的 5 个已知退化为：

- 2 个：目标单行同时翻译台词和说话人归属，算法丢掉归属源行；
- 1 个：目标把同一源句拆成声音/续句两行，算法丢掉其中一行；
- 2 个：相邻短行发生语义错位。

此外，保守 DLD 独自造成的错误主要是把确实合并翻译的短台词、首句或叙述行拆成 gap。
人工标签中的 necessity rank 覆盖几乎整个 `[0,1]`：正确合并与错误吸收高度重叠，因此
不存在一个有证据支持的 rank、cosine 或增益阈值能干净分开它们。

下一层证据需要观察句向量没有保留的信息。最值得验证的是只在模型分歧岛运行的双向
token/短语覆盖码：

1. 以候选目标块解释每个源短语，反向同理；
2. 用同文档其他候选块形成置换/秩 null；
3. 把实际对应相对 null 的 code saving 加到 `H_merge`；
4. 与真实的 `H_subblock+gap` 路径做 description-length difference；
5. 若两向覆盖仍冲突，继续拒绝自动裁决。

它能直接检查姓名、说话动词、短回答和注释专有词是否真的在译文中出现；新增计算只与
模型分歧岛数量和短语数有关，而不是恢复 `n*m` 全文交叉编码。若使用生成式翻译似然或
跨编码器，也应在独立语料上校准其 code，而不是把 logits 乘经验常数。
